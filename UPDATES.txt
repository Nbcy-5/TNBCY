TNBCY in-game updates (GitHub)

WHAT THE PLAYER SEES
- On start the game looks for a newer version. If there is one, a window says "New version available" with what is new.
  Download opens the APK link in the browser, then the player taps the file to install it over the old game. Later closes the window.
- No internet, or nothing new: nothing is shown and the game just starts.

HOW IT WORKS
- Each GitHub build publishes a release (TNBCY.apk, content.pck, version.json) to the PUBLIC repository  Nbcy-5/tnbcy-updates.
  (The main repository stays private: a private repository cannot be read by the game.)
- The game reads  https://github.com/Nbcy-5/tnbcy-updates/releases/latest/download/version.json  (set in Data/update_config.json).
- version.json says which version code is newest. If it is higher than ApkVersion in Scripts/Updater.cs the window appears.

ONE-TIME SETUP (Termux)
  gh repo create Nbcy-5/tnbcy-updates --public --add-readme
  gh auth token | gh secret set UPDATES_TOKEN -R Nbcy-5/TNBCY
  (the token lets the build upload releases to the updates repository)

EVERY NEW VERSION
- Raise  version/code  in export_presets.cfg and  ApkVersion  in Scripts/Updater.cs to the SAME number (the build stops if they differ).
- Push as usual. The build publishes the release; phones that have this updater see the window next time they start the game.
- Android only lets an update install if it is signed with the same key (your tnbcy key) and has a higher version code.

LIMITS
- C# code and new files always need a new APK (Android does not let an app replace its own compiled code).
- content.pck (data files only) is published too; it is only used if you later publish a content number higher than the APK number.
